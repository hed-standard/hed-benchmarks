# JSON specifications - synthetic search

This directory will hold the standardized JSON specifications for this use case - its case descriptor and the run input/output definitions - once the benchmark JSON format is designed. The JSON Schema definitions that these documents validate against live in `json_schemas/` at the repository root.

Until the format lands, this directory is a placeholder (this README exists so the directory is tracked by git), and the scripts in `../src/` define their own input and output.
